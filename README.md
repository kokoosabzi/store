# Local Commerce Core

یک سامانهٔ محلی و آفلاین برای فروشگاه‌های محصول‌محور. معماری پروژه یک Modular Monolith شامل FastAPI، SQLite و رابط Vue 3 راست‌به‌چپ است.

برای نصب و اجرای برنامه، فایل [`start`](start) را بخوانید.

## قواعد مهم پیاده‌سازی

- پیش‌نویس‌ها هیچ اثر مالی یا انباری ندارند.
- نهایی‌سازی فروش و خرید در یک تراکنش SQLite انجام می‌شود.
- بهای تمام‌شده در `SaleItem` ثبت می‌شود؛ گزارش سود به قیمت فعلی محصول وابسته نیست.
- هر تغییر موجودی یک `InventoryMovement` قابل پیگیری ایجاد می‌کند.

## پشتیبان‌گیری

پس از اجرای migrationها، `POST /api/backups` یک کپی سازگار با SQLite می‌سازد و با `PRAGMA integrity_check` و بررسی جدول‌های اصلی آن را اعتبارسنجی می‌کند. فایل‌ها به‌صورت پیش‌فرض در `backups/` قرار می‌گیرند.
