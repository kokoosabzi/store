# Local Commerce Core
## Phase 11 — Printing Implementation

### Receipt Formats
Primary:
- 80mm thermal

Optional:
- 58mm thermal
- A4

### Sales Receipt
Include:
- store information
- document number
- date/time
- customer where applicable
- items
- quantities
- prices
- discounts
- tax
- total
- payment
- remaining credit where applicable

### Purchase Printing
Support printable purchase documents where required.

### Return Invoice
Provide return document printing.

### Barcode Labels
Support configurable barcode label layout.

### Printer Configuration
Store local printing preferences.

### Preview
Important documents should support preview before printing where practical.

### Automatic Printing
Allow configuration for automatic printing after finalization.

### Copies
Allow configurable number of copies.

### Accuracy
Printed totals must come from the same finalized transaction data as the application.

### Offline
Printing must not depend on internet/CDN resources.

### Acceptance
Verify output on configured Windows printers and thermal formats.
